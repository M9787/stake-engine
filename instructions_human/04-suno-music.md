# 04 — Make the music with Suno (1 h)

**Why:** 3★ needs good sound, with no "laggy or low-quality sounds". You already have a paid Suno plan. Songs made while on a paid plan can be used commercially. Check Suno's current terms and tell the agent the date.

## Steps
1. Open `docs\09-assets.md` → "Music".
2. For each track (base loop, bonus loop, big-win sting, max-win sting, bonus intro sting):
   1. In Suno, choose **Instrumental** (no vocals).
   2. Paste the style prompt from docs/09.
   3. Make 2–4 versions and pick the best.
   4. Download as **WAV** if your plan offers it, otherwise MP3.
   5. Name it as in the table (for example `music_base.wav`).
   6. Save it to `C:\Users\User\Desktop\Claude Code\stake\audio_in\`.
3. Write the Suno song link next to each file in `audio_in\links.txt`. The agent needs it for the licence log.

## Done when
- 5 music files plus `links.txt` are in `audio_in\`. Tell the agent "music done".
