# 25 — After launch

**Goal:** Keep the game healthy, and push the team's Engine Insights rank up for the next release.

**Why:**
- New Releases are ordered by team 30-day Engine Insights rank (https://studio.engine.io/docs/approval-guidelines/game-quality-rankings, 2026-10-28).
- After approval only visual fixes are allowed.

**Depends on:** the game is live.

## Steps
1. Weekly, with the user's OK, read the team page on Engine Insights (https://stake-engine.com/insights) and Studio Accounting. Write the numbers to `launch\stats.md`: bets, players, rank, GGR.
2. Collect feedback from the reviewer thread, X replies and streamer comments. Sort each item as a visual fix (allowed) or a math/mechanic change (not allowed; save it for game 2).
3. Ship visual fixes as new front versions. The user publishes them (human task 06 steps).
4. Write lessons for game 2 in `docs\retro-oracle-of-sevens.md`.

## Done test
- `launch\stats.md` has weekly rows.
- Each feedback item is marked fixed, rejected (with a reason) or saved for game 2.
