# 05 — Get the sound effects (45 min)

**Why:** The game needs about 25 short effects: tumble, chime, slam, whoosh, click and so on. The sample sounds must all go.

## Option A — ElevenLabs Sound Effects (about $5–10, recommended)
1. Go to https://elevenlabs.io and subscribe to the cheapest paid plan (Starter). Check the price and confirm that its terms allow commercial use.
2. Open **Sound Effects**.
3. For each row in `docs\09-assets.md` → "Sound effects", paste the prompt, make 2–4 versions, and download the best.
4. Name each file as in the table and save it to `C:\Users\User\Desktop\Claude Code\stake\audio_in\sfx\`.

## Option B — free CC0 sounds
1. Use only **CC0** (public domain) sounds: https://kenney.nl/assets (audio packs) or https://freesound.org with the "CC0" licence filter.
2. Save each file to `audio_in\sfx\`. Write its page link in `audio_in\sfx\links.txt`.

You can mix A and B.

## Done when
- Every effect in docs/09 has a file. Tell the agent "sfx done".
