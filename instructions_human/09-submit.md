# 09 — Fill the tabs and click Submit (30 min)

**Why:** Only you can submit. Until your first game is live you can have only 1 review open. A fail locks the thread for 3 days, so submit only when everything is ready.

**Wait for:** agent tasks 22 (staging test) and 23 (`docs\submission.md`).

## Steps
1. Search the Stake lobby (on stake.com with your player account) for "Oracle of Sevens" and similar names. Tell the agent if you find a match.
2. Open https://studio.engine.io/teams/dumalex/games/oracle-of-sevens/approval.
3. Fill in each tab:
   - **Payment:** Guaranteed 7.5% (already chosen).
   - **Distribution:** **Only on Stake**. This is fixed at launch and cannot be changed later.
   - **Compliance:** copy the answers from `docs\submission.md`.
   - **Details:** copy the blurb and features from `docs\submission.md`.
4. Read everything once more, then click **Submit**.

## Done when
- The status shows "Rating queue". Tell the agent "submitted" and the date.
